# Benedict's Portal

A simple, modern, and responsive portal to navigate between my various web services and projects.

## Tech Stack
- Vanilla HTML5
- Vanilla CSS3 (CSS Grid & Flexbox)
- Vanilla JavaScript

## Projects Included
- **Markdown-to-PDF**: Professional markdown converter.
- **QRender**: Artistic micro-dot style QR code generator.
- **Personal Website**: Next.js based platform & CMS.

## Deployment
This project is hosted at [portal.ben.winlab.tw](https://portal.ben.winlab.tw) (assumed target domain).
